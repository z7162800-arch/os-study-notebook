# 作業系統・演算法學習題庫
此版本只需 GitHub Pages。網站包含查題、練習、黃標速讀、批次查題，以及題目與答案匯入。
匯入只儲存在目前的瀏覽器，不會跨裝置同步；原站的共享寫入、管理員後台及回報功能需要後端，未包含在本版本。
題庫包含原網站程式內建資料，以及 2026-10-31 已保存的公開共享題庫資料；此日期後只儲存在伺服器的題目不一定包含。
## GitHub Pages 發布
1. 在自己的 GitHub 帳號下建立專用公開 repo，例如 os-study-notebook。
2. 上傳此資料夾內的檔案與 assets 資料夾，讓 index.html 直接位在 main 分支根目錄。
3. 在 Settings → Pages，選擇 Deploy from a branch、main、/(root)，再按 Save。
4. 部署完成後以 Pages 設定顯示的網站網址為準。
